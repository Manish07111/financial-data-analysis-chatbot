# Financial Data Analysis & Chatbot

## About
A Python-based project for analyzing financial data of
Microsoft, Tesla and Apple for FY2023–2025.

## Technologies Used
- Python
- Pandas
- CSV
- Jupyter Notebook

## Features
- Search financial data by company
- Select fiscal year
- Retrieve financial information
- Calculate year-over-year trends
- Simple rule-based chatbot

## Companies
- Microsoft
- Tesla
- Apple

## How to Run

1. Install Python
2. Install Pandas
3. Download or clone this repository
4. Run financial_chatbot.py
